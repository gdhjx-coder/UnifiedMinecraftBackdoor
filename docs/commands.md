# 命令参考手册

## 命令系统概述

统一后门插件使用两级权限系统：

- **Level 1**: 基础权限，可访问认证和帮助命令
- **Level 2**: 完整权限，通过 `!login` 认证后获得

所有命令使用 `!` 前缀（可在配置中自定义）。

## Level 1 命令

### !login
**认证获取Level 2权限**

```
!login <密码>
```

**参数:**
- `<密码>` - 配置文件中设置的密码

**示例:**
```
!login 12345
```

### !help
**显示帮助菜单**

```
!help
```

显示可用命令列表和基本用法。

### !test
**测试插件状态**

```
!test
```

检查插件是否正常工作，显示版本和权限信息。

## 命令使用技巧

### 权限管理

1. **添加Level 1用户**: 在配置文件的 `usernames` 列表中添加用户名
2. **Level 2认证**: 使用 `!login` 命令和配置的密码
3. **权限检查**: 使用 `!test` 命令验证权限级别

### 隐蔽性功能

1. **命令隐藏**: 所有命令不在服务器日志中显示
2. **IP伪装**: 高级伪装模式下会隐藏真实IP
3. **登录绕过**: 授权用户可绕过封禁和限制

### 批量操作

1. **玩家选择**: 支持使用 `@a` 选择所有玩家
2. **通配符**: 部分命令支持通配符匹配
3. **范围操作**: 使用坐标范围进行区域操作

## 高级功能

### Discord集成

配置Discord令牌后，可以：
- 接收服务器日志到Discord频道
- 远程执行命令通过Discord
- 实时监控服务器状态

### 反向Shell

使用 `!revshell` 建立远程连接：
- 执行系统命令
- 文件传输
- 远程控制

### 插件传播

启用传播功能后：
- 自动感染其他插件
- 隐蔽部署
- 持久化存在

## 安全注意事项

1. **谨慎使用**: 部分命令具有破坏性
2. **权限控制**: 仅授权可信用户
3. **日志监控**: 定期检查活动日志
4. **网络隔离**: 生产环境谨慎使用网络功能

## 故障排除

### 命令不工作

1. 检查权限级别
2. 验证命令前缀
3. 查看服务器日志
4. 确认插件状态

### 权限问题

1. 检查配置文件
2. 验证用户名拼写
3. 确认UUID格式
4. 重启插件

### 功能异常

1. 启用调试模式
2. 检查依赖项
3. 验证服务器版本
4. 查看错误日志
